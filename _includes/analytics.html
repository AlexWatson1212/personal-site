{%- comment -%} Analytics. Nothing is emitted unless _config.yml supplies BOTH a provider and a domain. Unconfigured, this include renders zero bytes and the site makes no third-party request at all — which is its state today. Plausible is the only implemented provider: cookieless, no persistent identifier, no cross-site profiling, no advertising network, and roughly 1 KB. It is chosen because it can answer the business questions without collecting anything a therapist would mind being collected. What is measured: page views, and a short allowlist of named events declared with data-analytics="…" attributes. What is never measured: anything a person types. See assets/js/analytics-events.js, which reads element attributes only and never reads a form value. Turning this on also needs two lines uncommented in netlify.toml, because the Content Security Policy does not permit a third-party script by default. {%- endcomment -%} {%- assign provider = site.analytics.provider | default: "" | strip -%} {%- assign domain = site.analytics.domain | default: "" | strip -%} {%- assign host = site.analytics.host | default: "" | strip -%} {%- if provider == "plausible" and domain != "" and host != "" -%} {%- endif -%} {%- comment -%} ─────────────────────────────────────────────────────────────────────────── Google Analytics 4. Everything below emits is one small configuration object and one first-party script. Nothing from Google is requested here. gtag.js is injected by assets/js/analytics-consent.js, and only after a visitor has actively chosen to allow it — so on a first visit, and on every visit after a visitor has declined, this page makes no request to googletagmanager.com, sets no _ga cookie, and Google is told nothing at all. That is the whole reason the tag is not simply pasted into the head, which is what Google's own instructions say to do. The measurement ID lives in _config.yml and appears in exactly one place in the templates: here. The host allowlist is the production guard — the script compares location.hostname against it before it will load anything, so a local preview or a Netlify deploy preview cannot report a visit even with consent already stored in that browser. This include is only reached from _layouts/default.html, which the studio site's pages use. The concept sites in _concepts/, the deployment copies in _deploy/ and the shared components in _shared/ are separate builds and are excluded from this one in _config.yml, so none of them can pick this up. ─────────────────────────────────────────────────────────────────────────── {%- endcomment -%} {%- assign ga4 = site.analytics.ga4_measurement_id | default: "" | strip -%} {%- if ga4 != "" -%} {%- endif -%}
