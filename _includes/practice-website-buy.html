{%- comment -%} Choose Your Practice Website purchase action — the single source of truth for the £995 buy action. No other file may render a checkout link. Configuration comes from two data files: site.data.purchasing committed prices and route URLs site.data.purchasing_resolved generated at build time by scripts/purchasing-config.mjs This include re-validates the resolved link rather than trusting it. It renders a real checkout link ONLY when the build resolved purchasing to on AND the URL still begins https://buy.stripe.com/. In every other case — including a missing generated file — it renders the "opening shortly" state and keeps the "Ask a question first" route working. A Payment Link URL is public by design. A Stripe secret or restricted key (sk_…, rk_…, whsec_…) must never appear in this repository.
