{%- comment -%} Therapist Website — how a project begins. The single source of truth for the purchase action. No other file may render a checkout link. August 2026. The route is deliberately human and is not a fallback: the client names a design, the scope and price are confirmed in writing, and a payment link for the first instalment is sent directly. That is what this component says by default, stated positively — the site does not apologise for having no self-service checkout, because self-service checkout is not the offer. Configuration comes from two data files: site.data.purchasing committed prices, the canonical payment sentence, and route URLs site.data.purchasing_resolved generated at build time by scripts/purchasing-config.mjs If a Payment Link is ever resolved at build time AND still begins https://buy.stripe.com/, the first instalment is offered directly and the written route becomes the secondary action. In every other case — including a missing generated file — only the written route is shown. There is no disabled control and no "opening shortly" state: an action a visitor cannot take is not an action. A Payment Link URL is public by design. A Stripe secret or restricted key (sk_…, rk_…, whsec_…) must never appear in this repository.
