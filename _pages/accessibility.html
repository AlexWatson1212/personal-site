Accessibility

Accessibility Statement

I want this website to be clear, readable and usable by as many people as possible, including people who use assistive technologies.

What this website supports

The website has been designed with:

  • visible keyboard focus states for interactive controls;
  • keyboard-operable navigation;
  • reduced-motion preferences;
  • useful alternative text for meaningful images;
  • responsive layouts that adapt to different screen sizes; and
  • clear headings, readable structure and straightforward language.

Known limitations

I continue to review the website as content and features change. Embedded PDF documents may not work equally well in every browser, so each one is also available through a direct link that opens the document separately.

Report an accessibility problem

If anything on this website is difficult to access or use, please email hello@alexanderwatson.co.uk. If you include the page address and a short description of the problem, I will investigate and respond as soon as reasonably possible.
